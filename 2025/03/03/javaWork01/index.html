填空题

1.Java是一种面向对象的语言，它是由Sun公司开发的高级程序设计语言。

2.Java语言的特点有简单、面向对象、平台无关性、安全性、支持多线程和分布性。

3.将.java源文件编译为.class 文件的是javac命令。

4.Java语言的跨平台特点是由Java虚拟机保证的。

5.Java程序的运行环境简称为JRE。

1.JRE中包含了Java基本类库、JVM 和开发工具。

  • 正确
  • 错误 √

3.IDEA开发工具 Debug模式下不进入函数内部的单步调试快捷键是F7。

  • 正确
  • 错误 √

  • 正确 √

1. Java 属于( )。

  • A.机器语言
  • B.汇编语言

  • A.简单 √
  • B.面向对象 √
  • C.跨平台性 √
  • D.支持多线程 √

  • A.Java 文档制作工具
  • B.Java 解释器
  • C.Java 编译器
  • D. Java启动器 √

4.以下选项中，( )属于 JDK 工具。(多选)

  • A. Java 编译器 √
  • B.Java 文档生成工具 √
  • C. Java 运行工具 √
  • D. Java 打包工具 √

5.下面4种类型的文件中( )可以在 Java 虚拟机中运行。

  • A. .java
  • B. .jre
  • C. .exe
  • D. .class √

简答题

1.简述Java语言的特点。

答：Java是一种面向对象、跨平台的高级程序设计语言，Java语言的特点有简单、面向对象、平台无关性、安全性、支持多线程和分布性。

2.简述Java的运行机制。

答：Java程序的运行环境简称为JVM，JVM是Java语言的运行环境，它负责字节码的解释和执行。Java程序的运行机制是编译后产生.class文件，然后由JVM执行。
